Telemetry is different, because it needs something to read. TMM keeps its counters in shared memory inside the pod, so an exporter has to be in there with them. Field adds one as an ephemeral container. TMM keeps running, nothing restarts. The exporter reads that memory read-only and serves metrics, and the iPad scrapes it through a port forward. That detail matters more than it sounds. TMM hooks inbound TCP on its dataplane interfaces, so nothing outside the pod can dial that port. Port forward enters the pod's network namespace instead, and reaches it from within. A couple of seconds later, the charts are live.
